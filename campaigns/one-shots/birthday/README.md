# The Lost Celebration of Bellweather

A complete birthday-themed D&D one-shot for three level 3 heroes, written for the 2024 fifth-edition rules. It is designed for players around age 13, a first-time Game Master, offline play, and an expected runtime of 3½–4½ hours.

The heroes must recover four strangely named components and rebuild Bellweather's forgotten celebration item. The finished object remains a mystery until the final reveal.
